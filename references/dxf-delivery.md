# DXF 交付与回读验收

最终成果是一个可编辑 DXF。本文件负责格式、CAD 结构、回读和目标阅读器兼容性；投影简化与去碎片由 [投影复杂度规则](projection-complexity.md)负责。

## 1. 文件契约

1. 默认输出 `<前缀>_六视图压铆标注.dxf`，同一图幅包含六个主视图、尺寸、压铆类别表、技术要求、版本履历和联合标题栏；不拆页、不加轴测图，不另建普通孔明细文件。
2. DXF 版本服从用户/加工厂要求；未指定时选择导出器和接收方已验证、能保留中文、尺寸、图层和所需实体的最低兼容版本。记录 `$ACADVER`、ASCII/二进制形式和导出器。
3. 单位为 mm，并写入适用头变量。模型空间原则上按 1:1；使用纸空间时，图幅、打印设置和标称比例必须一致。禁止用未声明整体缩放修补单位错误。
4. 不依赖未交付的 XREF、底图、字体或临时绝对路径。项目允许外部参照时使用相对路径并列出依赖。

## 2. 可编辑 CAD 结构

1. 轮廓使用 `LINE/ARC/CIRCLE/LWPOLYLINE/POLYLINE/SPLINE` 等可编辑几何；尺寸优先 `DIMENSION`，引线优先 `LEADER/MLEADER`，文字使用 `TEXT/MTEXT`，重复且无遮挡差异的图形可用 `BLOCK/INSERT`。导出器不能保留关联尺寸时记录限制，并逐项复核显示值。
2. 可见、隐藏、中心、尺寸、文字、压铆位号、说明、表格和图框/标题栏分层。至少保证 `VISIBLE/HIDDEN/CENTER/NOTES/TABLE/TITLEBLOCK` 可独立编辑、开关和打印；图层颜色、线型、线宽、线型比例和打印属性导出前后保持一致。
3. 使用任何非连续线型前先在 DXF 线型表中定义。显式写入并回读核对全局、纸空间/模型空间和实体线型比例；虚线图案按最终纸面毫米选择，必须在声明比例下表现为清楚的“线段＋间隔”，不得细密成点。回读发生线型替换、比例漂移或自动修复必须返工。
4. 表格、标题栏和第三角法符号按[表格规范](notes-tables-titleblock.md)输出为可编辑线、圆弧、文字、块或目标版本可靠支持的表格/属性实体；不得栅格化。
5. 中文字体、编码及 `⌀/R/±/°` 等符号必须在目标 CAD 和打印预览中完整显示；缺字、问号、乱码或未声明字体替换均不通过。

### 2.1 图线基准

项目/加工厂模板优先；未指定时使用下表。线宽是最终纸面线宽，颜色只用于屏幕分层，不代替线型和线宽。

| 图层 | 线型 | 默认线宽 | 用途 |
| --- | --- | ---: | --- |
| `BORDER` | `CONTINUOUS` | `0.35 mm` | 图框 |
| `VISIBLE` | `CONTINUOUS` | `0.25 mm` | 可见外轮廓、可见孔槽和折边 |
| `HIDDEN` | `DASHED` | `0.13 mm` | 实际被遮挡且需要表达的内部轮廓 |
| `CENTER` | `CENTER` | `0.13 mm` | 轴线、中心线和对称线 |
| `DIMENSION` | `CONTINUOUS` | `0.18 mm` | 尺寸线、尺寸界线和引线 |

1. 线宽层级必须满足 `BORDER ≥ VISIBLE > HIDDEN ≥ CENTER > 0`；尺寸线清晰但不得压过可见轮廓。模板另有规定时记录覆盖值，并在回读后验证。
2. 线型必须在 DXF 线型表中真实定义。当前验证通过的 A1、比例 `2:3` 基准为：`$LTSCALE=1`，实体 `ltscale=1`，`DASHED=[4.0, 3.0, -1.0]`（3 mm 线段、1 mm 间隔），`CENTER=[8.0, 5.0, -1.0, 0.5, -1.5]`。其他比例以最终纸面约 `2～4 mm` 隐藏线段和 `0.6～1.5 mm` 间隔为目标反算模型空间图案，不直接照搬数值。
3. 禁止使用 `0.3 mm 线段 + 0.3 mm 间隔` 一类在目标比例下呈点状的隐藏线。虚线过密、过疏、相位因碎实体反复重启或圆弧显示成点列均须返工。
4. 完全重合的 `VISIBLE/HIDDEN` 实体必须删除隐藏副本；部分重合必须切分并删除重合隐藏区。每个视图先写 `HIDDEN`、后写 `VISIBLE`，且最终 DXF 的 `visible_hidden_exact_overlap` 必须为零。
5. 直线、圆弧和整圆分别使用解析 `LINE/ARC/CIRCLE`。只有目标 DXF 不支持或解析恢复失败的曲线才允许离散，并须记录源边、误差和原因。

## 3. 导出与回读

1. 从本次导入的 STEP 和当前生成对象直接导出；不得复用旧固定实体、改扩展名或嵌入不可编辑中间格式。
2. 导出前核对单位、图层、字体、块、尺寸样式、六视图数量/位置/比例、图幅、第三角法标题栏和 `FREECAD_<front_source> → DRAWING_FRONT`；保存 HLR 原始/优化/待导出统计。
3. 关闭源文档后，用可解析目标版本的 CAD 读取器重新打开最终 DXF。记录版本、单位、范围、图幅/打印比例、样式、块、实体类型/数量、折线顶点、文件大小和哈希；检查异常远点、丢失引用、字体替换和符号缺失。
4. 先运行 `scripts/dxf_text_audit.py <最终.dxf> --check <工程图检查记录.json> --json-out <DXF文字审计.json>`。该脚本必须直接读取最终 DXF；工程图检查记录须提供每个 `TABLE/TITLEBLOCK` 文字 handle 对应的真实单元格边界，并在 `table_layout.titleblock_topology.merged_regions` 提供标题栏六个必需合并区。脚本独立重算字体解析、实际字形框、四向净距、格高比和线框相交，同时检查 `tolerance_title/drawing_name/unit/unit_value/projection_symbol/company_name` 内部没有 `TITLEBLOCK` 网格线。文字 handle 缺失/陈旧、合并区缺失、字体替换、字形框不可得、越格、压线、净距不足、格高比失败或合并区内部存在贯穿线，均不得继续交付。
5. 运行 `scripts/dxf_performance_audit.py`。审计错误、审计修复、非有限坐标、同层精确重复投影和 `VISIBLE/HIDDEN` 精确重合必须均为零；图层线型及线宽层级必须通过，项目提供的实体、顶点、文件大小和回读耗时上限必须全部通过。
6. 只从最终 DXF 生成高分辨率回读预览。无界面脚本须使用非交互后端，保存后关闭图形和 CAD 文档并正常退出；图片已生成但进程挂起仍判失败。
7. 查看最终预览的整体图幅和关键局部后，运行 `scripts/record_projection_review.py --check <工程图检查记录.json> --preview <回读预览.png> --visible-contour-breaks <数量> --missing-internal-features <数量> --hidden-pattern-issues <数量> --reviewer <检查人>`。该步骤必须发生在预览生成后；脚本把结果与预览 SHA-256 绑定，禁止生成器在出 DXF 时预置通过。

## 4. 几何、版面和目标 CAD 验收

1. 回读后按同一图幅复核六视图名称、方向、镜像、共同投影基准、统一比例、尺寸、压铆位号、图框、贴边表格、技术要求、标题栏和打印设置。每个视图至少用三个不共线特征执行“STEP → 图上实体 → 回读 DXF”核对。
2. 抽查可见边、遮挡边和轴线分别位于 `VISIBLE/HIDDEN/CENTER`；独立 DXF 审计必须确认 `visible_hidden_exact_overlap=0`，部分重合区也须经局部预览确认已裁掉隐藏段，且隐藏线先写、可见线后写。逐视图检查 FreeCAD HLR 全部分组已被记录并按规则选择，源模型中的功能性内部轮廓在最终 DXF 中有对应可见线或隐藏线；全部关键尺寸显示值与检查记录一致。
3. 在 100% 打印预览及局部放大状态检查线条：可见轮廓连续、清晰且无点状断口；隐藏线段和间隔可辨、相位不因微小实体反复重启；圆和圆弧保持解析和光顺；内部孔槽、压铆件内外轮廓无漏投。任一项失败即回到投影/导出源修复。
4. 抽查 `NOTES/TABLE/TITLEBLOCK` 的实体类型和可编辑性，并按专项规则核对表格贴边、字形/格高比、文字字形框是否完全位于所属单元格安全区、文字与表格线相交数、版本履历空白行、类别规格/总数、标题栏字段和张次；回读预览中出现压线、跨行或标题骑在外框线上时直接返工。
5. 在加工厂指定或项目常用 CAD 中执行打开、全图、连续缩放/平移、局部放大、图层切换、打印预览和保存副本；记录软件版本、硬件、打开耗时、文件大小和实体/顶点数量。卡死、崩溃、超时或明显失去响应即返工；无法访问时只能记录“待目标阅读器验证”。

**通过条件：** 单一 DXF 可打开、编辑、保存并按声明图幅/比例打印；六视图、尺寸和表格与源模型及图幅评估一致，无碰撞、裁切、镜像错误、乱码、未打包依赖或结构审计问题；目标 CAD 交互测试通过。工程批准与投产放行另按项目流程办理。

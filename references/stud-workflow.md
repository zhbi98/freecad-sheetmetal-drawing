# 压铆柱识别、分面与分类

本流程中的“卯柱”对应压铆柱/压铆件。所有实例、尺寸、类别、面和位号从当前 STEP 生成，不沿用旧图；表格外观统一由[表格规范](notes-tables-titleblock.md)维护。

## 1. 找出实例并测量

1. 展开装配树，区分钣金本体、装配容器/复合副本和独立零件，避免父子重复计数。优先保存 STEP 产品名、装配路径、实例关系和放置矩阵；本项目源名称含 `3D` 或已确认的压铆料号只用于进入候选清单，导入器改名时回查 STEP 实例关系。
2. 禁止把“非钣金实体”“包围盒小于某阈值”或“外形近似圆柱”直接等同于压铆件。候选必须同时核对装配身份、独立实体、同轴外圆柱/内孔、对应钣金安装孔、轴线同心及合理接触/装配间隙；垫片、普通螺母、螺钉、小支架和装饰件应排除。
3. 为全部候选记录 `confirmed/rejected/pending` 状态及理由，并在 `fastener_candidate_summary` 保存 `candidate_count/confirmed_count/rejected_count/pending_count`。只有 `confirmed` 实例进入 `fasteners`、分类表和图面位号；关键来源、安装孔、轴线或接触关系不明时保持 `pending`，不得先标注再等待人工纠正。
4. 柱轴从同轴圆柱面集合求得，并用相反圆边、内孔轴线和安装孔轴线交叉验证。禁止用包围盒最短/最长方向、对象局部 XYZ 名称或外形长宽比代替真实轴线。
5. 保存源标签/标识、产品名、装配路径、放置矩阵、轴线原点/方向、安装孔标识、三维孔心、外径、内径、独立实体轴向总长和实体包络。独立实体轴向总长只用于实体拓扑、接触与投影证据，不作为分类高度；分类高度须在确认安装关系后按第 2 节从压铆进入的背面量到柱体自由端。
6. 外径取安装后柱身连续圆柱段，排除压入齿、倒角和头部/法兰；内径取有效孔圆柱段，排除入口倒角和局部沉孔。用卯柱自身实体拓扑沿柱轴检查内孔：两端均存在开口且中心空腔连续贯穿实体才记 `hole_type=through`；只有一端开口、空腔连续至唯一封闭孔底才记 `hole_type=blind` 并测量从开口端到孔底的 `blind_hole_depth`；两端状态、空腔连通性或孔底不明确时记 `hole_type=pending`。不得以单个内圆柱面的轴向长度、钣金安装孔是否贯穿或名称中的文字代替该判断。多个候选圆柱段、精度不足、非单一有效实体或非圆柱异形件先查确认资料，仍不明确则保持 `pending`。
7. 逐件读取与卯柱实例唯一关联的非空 3D 辅助字符串。去除首尾空白，把 `×/X` 统一解析为螺距分隔符，并在字符串任意位置搜索有效公制螺纹规格；不是只检查字符串开头。字符串包含恰好一个规范化规格（如 `M2.5`、`M3`、`M4x0.7`、`M6-6H`）时，登记 `manufacturing_hole_kind=threaded` 和完整 `thread_designation`；字符串存在但没有有效螺纹规格时，登记 `manufacturing_hole_kind=unthreaded`、`thread_designation=null`。普通单词中的字母 M、空字符串、孤立的 `M`、缺少直径的 `Mx` 及边界不完整的字母数字串不是螺纹规格；同一字符串出现两个不同螺纹规格时保持 `pending`。辅助字符串可来自 STEP 产品/实例标签、独立命名文字对象，或与 STEP 哈希绑定的人工三维审查记录；仅有不可语义读取的字形轮廓时必须保存关联实例、文字内容、证据视图/对象及确认状态。多个来源若一个判定有螺纹、另一个判定无螺纹，或给出不同螺纹规格，也必须保持 `pending`。孔型与螺纹需求是独立字段：`threaded-through`、`threaded-blind`、`unthreaded-through`、`unthreaded-blind` 四种组合均可出现。孔型只由第 6 项的实体拓扑产生，螺纹需求只由本项辅助字符串产生；禁止因螺纹而默认盲孔、因盲孔而默认螺纹、因通孔而默认无螺纹，或因无螺纹而默认通孔，也不得以没有建模牙型覆盖辅助字符串结论。覆盖率按实例计算；整套模型可以全为 `threaded`、全为 `unthreaded` 或两类混合。

**产出：** 每个候选实例恰好一条判定记录；候选总数等于确认、排除和待确认数量之和，只有确认实例进入后续分类。

## 2. 分开判定安装板外表面、安装接触侧和柱身侧

1. 结合头部、法兰、压花/台阶、接触关系和确认资料识别压入/支承端。登记同一安装孔的两个孔口、面和法向；两个孔口属于同一通孔，不能因距离近就认定安装侧。孔中心取孔轴线与安装面的交点，并核对压铆轴线同心。同一无限轴线上存在多个钣金孔时，逐个计算孔壁轴向区间与压铆实体轴向区间的重叠量和最近间隙，只能选择具有实际重叠或接触间隙的本地安装孔；不得使用容器遍历顺序中的第一个同轴孔。
2. 压入/支承端实际贴合的钣金表面定义**安装接触面/安装侧**；它可能是外表面，也可能是内表面，不得自动等同于安装板外表面。检查接触段、板厚和另一侧露出；面法向只描述已确认的面，不能单独决定结构内外。
3. 以该安装孔所属钣金本体的局部板厚中面为分界，检查柱身连续主圆柱在板两侧的轴向范围；主段实际伸出量较大的一侧定义**柱身所在侧**，其相反的板面定义本项目压铆进入的**背面基准**。逐件保存安装孔轴向范围、中面坐标、局部板厚、压铆实体轴向范围、低端/高端伸出量、柱身侧露出量、背面基准坐标、柱体自由端坐标和最终柱身方向向量。分类高度固定为 `H = 柱身侧露出量 + 安装孔处局部板厚 = |柱体自由端坐标 - 背面基准坐标|`；若直接按后一个等式测量，禁止再次加板厚。头部、压花或嵌入板内短段不能代替柱体自由端或露出量，独立实体轴向总长不能代替 `H`。圆柱曲面 `Axis` 的正方向只属于参数化方向，禁止用它直接决定 TOP/BOTTOM、LEFT/RIGHT 或 FRONT/REAR；也不得从安装面法向、全局坐标正负、模型原点、整体包围盒、最近孔口或视图名称推断柱身侧。
4. 独立确认安装孔所属板件的**结构外表面**。证据至少组合使用板件归属、局部板厚两表面、相邻围护板/结构内腔关系、外部可达方向和已确认设计输入；整体包围盒极值或到模型中心的距离只能辅助筛选，不能单独定案。不得以柱身伸出侧的相反方向代替外表面，也不得按全局坐标正负、圆柱 `Axis` 正负、模型原点或最近孔口猜测。证据冲突、内外均开放、内部隔板或局部凹腔导致外侧不唯一时标记 `pending` 并停止正式标注。
   用户或项目资料已逐件确认外表面时，将其作为受控输入写入检查记录的 `confirmed_inputs.installation_outer_sides`，格式为 `{源实例: FRONT|REAR|LEFT|RIGHT|TOP|BOTTOM}`；审计可以采用该输入消除几何歧义，但不得由生成器为了通过审计自行填充，也不得用类别或邻近实例批量外推未确认项。
5. 安装板外表面、安装接触侧与柱身侧是三个独立字段，可以相同也可以相反，必须分别记录。柱身跨两侧、露出相近、折边/台阶复杂或装配干涉时使用隔离三维视图/剖视和零件资料核定；无法核定则待确认。
6. 目标标注视图由安装板外表面的外法向映射到 DRAWING 六方向唯一确定。柱身伸出方向只用于记录 `inward/outward`：若柱身朝结构内部延伸，位号、分类标注和类别色轮廓仍放在安装板外表面视图；不得换到柱身所在侧。遮挡时先调整主视图标注；确实不能唯一表达时，才可按[局部图、剖视和辅助视图门禁](feature-dimensions.md#局部图剖视和辅助视图门禁)增加双向可追溯的补充视图，但补充视图不能改变位号的主视图归属。

逐件证据链至少包含：源实例与装配路径、候选判定、安装孔及两孔口、轴线/孔心、局部板厚及中面、压铆进入背面基准、柱身侧露出量、柱体自由端、包含局部板厚的安装总高度及计算式、安装板外表面/外法向/判定依据、安装接触面/侧、柱身轴向范围/侧、向内或向外状态、目标视图、视向和位号。用至少三个不共线特征核对相反视图的镜像。

**产出：** 每个已标实例恰好属于一个安装板外表面视图；六侧计数之和等于已确认实例数。计数相等不能代替逐件判面。

## 3. 位号锚点与同源投影

1. 三维位号锚点固定取压铆轴线与已确认安装板外表面或局部板厚中面的交点，即安装孔中心；不得使用压铆件包围盒中心、实体质心、文字插入点或最近二维圆心代替。
2. 每个 DRAWING 视图建立唯一的模型到视图二维变换和视图到图幅变换。HLR 几何、安装孔中心、压铆锚点、尺寸落点和视图包围盒必须共用这两级变换；不得另写 `FRONT=(x,z)`、`RIGHT=(-y,z)` 等按视图猜测的坐标公式。
3. 若 `TechDraw.projectEx()` 的局部二维轴向、旋转或符号无法由当前接口直接取得，使用同一接口投影三个不共线校准特征，或在锚点处投影小型三维十字/圆环，从实际返回几何反求二维中心。校准几何只用于计算和证据，不进入最终可见图层。
4. 位号锚点先转换为视图局部坐标，再按该视图实际统一比例和图幅平移转换到最终 DXF 图幅坐标。移动文字避让时只移动文字并使用引线，锚点仍保持在安装孔中心。
5. 最终 DXF 为每个确认实例保存一个可回读锚点实体，建议放在不打印的 `STUD_ANCHOR` 图层并使用 `POINT/CIRCLE/INSERT`；同时把实例位号作为 `STUD` 层的 `TEXT/MTEXT/ATTRIB` 保存并记录 handle。`STUD` 层只允许放置逐件可见位号，不得混入类别表或说明文字。锚点实体不得由预览图片或生成器内存坐标代替。
6. `annotation_validation` 必须保存六视图变换标识与校准残差、图幅视图边界、纸面位置容差及逐件记录。逐件至少包含：`source`、`tag`、`classification_status`、身份/几何/安装孔/安装板外表面/柱身侧确认状态、`axis_method`、柱轴原点/方向、`hole_type`、`open_end_count`、`bore_continuity_confirmed`、`blind_hole_depth`（盲孔适用）、孔型拓扑证据、`auxiliary_mark_text`、`thread_designation`（仅螺纹件适用）、`auxiliary_mark_source`、`mark_status`、`manufacturing_hole_kind=threaded|unthreaded`、完整 `classification_key`、安装孔轴向范围/重叠/间隙/中面、`local_sheet_thickness_mm`、`body_side_exposed_height_mm`、`press_in_back_face_coordinate`、`free_end_coordinate`、`height_basis=press_in_back_face_to_free_end_includes_local_sheet_thickness`、包含局部板厚的 `height`、`installation_outer_side`、`exterior_side_confirmed`、`exterior_side_basis` 及判定证据、`body_side`、压铆实体轴向范围、两侧伸出量、柱身方向向量、`body_extension_relation=inward|outward`、`anchor_kind`、三维锚点、目标视图、`projection_method`、`view_transform_id`、期望图幅坐标、锚点实体 handle、位号文字 handle、回读坐标偏差、是否落在目标视图内、是否匹配该安装特征和 `pass`。`target_view` 必须等于 `installation_outer_side`，不能等于 `body_side` 作为默认规则。

默认纸面位置容差为 `0.10 mm`；项目模板另有要求时采用更严格或明确指定的值。若仅有已确认实例的锚点/位号缺失，而该实例的身份、安装孔、安装板外表面、目标视图及三维锚点均由独立 STEP 审计确认，则只补该实例的锚点和位号并同步逐件记录，保留已有正确位号。目标视图错误、变换标识不一致、锚点越界、无对应安装特征、重复/错误位号或回读偏差超限不属于单纯漏标，必须修正对应生成源；相反视图中的错误位号必须删除，不能只在外表面视图补一份形成重复标注。

**产出：** 每个确认实例从三维安装孔中心到最终 DXF 锚点具有唯一、可回读且可量化偏差的映射。

## 4. 分类、颜色和位号

1. 分类键为 `(内径, 柱体外径, 包含安装处局部板厚的安装总高度, hole_type, blind_hole_depth_if_blind, manufacturing_hole_kind, thread_designation_if_threaded)`。高度必须同时满足 `height = body_side_exposed_height_mm + local_sheet_thickness_mm` 和 `height = |free_end_coordinate - press_in_back_face_coordinate|`；任一高度证据缺失或两式不一致即保持 `pending`。`hole_type` 与 `manufacturing_hole_kind` 必须分别写入，形成独立的笛卡尔组合，不设置“螺纹＝盲孔”或“通孔＝无螺纹”一类默认映射。优先比较确认的公称尺寸；否则使用未舍入模型值和记录的几何容差。显示小数位不是分类容差，任一项有实质差异即另分类。内径、外径和高度相同但通孔/盲孔不同、`threaded/unthreaded` 不同或螺纹规格不同，必须分为不同类别；两个盲孔深度不同也不得合并。
2. 安装面、颜色、源名称、数量、安装孔径及非螺纹辅助字符串的具体内容不属于分类键；3D 辅助字符串表达的有/无螺纹需求及识别到的完整螺纹规格属于分类键。同一完整分类键位于不同面仍属同类；孔型、盲孔深度、辅助字符串关联、螺纹规格边界或精度不明时保持 `pending`，不得强行合并或按没有牙型推翻字符串判定。
3. 按稳定规则分配 A、B、C…及每类独有的高区分度颜色；视图和表格保持一致，并保留字母以支持黑白打印。
4. 同类位号为 `A1/A2…`。优先保留已核对源实例顺序；新编号时记录稳定坐标排序规则和坐标系。每个实例位号唯一，只在安装板外表面视图的已验证安装孔锚点附近出现一次。
5. 标记不得改变真实轮廓；密集处移动文字或使用引线，不让位号遮挡孔边和尺寸。
6. 在安装板外表面真形视图中，另外绘制该实例分类所对应的外圆和内圆轮廓，统一放在 `STUD_OUTLINE` 图层，并把两个轮廓实体的显式颜色设为该类别颜色；位号文字、类别表字母和轮廓颜色三者必须一致。轮廓只能使用解析圆/圆弧等可编辑实体，不得把投影边离散成短线，也不得为了着色修改、删除或重算受保护的可见/隐藏投影图线。每件记录外圆、内圆 handle、类别色以及模型内外径，供最终 DXF 回读核对。

**产出：** `源实例 → 3D 辅助字符串/螺纹规格 → 有/无螺纹加工属性 → 内孔拓扑/孔型 → 分类键 → 类别/颜色 → 位号 → 安装板外表面 → 安装接触侧 → 柱身侧/内外延伸 → 图上坐标` 的完整映射。

## 5. 图面表格和可选坐标

1. 类别表为必需项，固定三列“类、规格、总数”。规格串统一使用 ASCII 兼容的 `d/D/H/DP/THRU`、半角 `*` 和 `-`，去掉无意义尾零；小写 `d` 表示光孔内径，大写 `D` 表示柱体外径，`H` 表示从压铆进入背面到柱体自由端、包含安装处局部板厚的安装总高度；类别表内禁止使用 `ID/OD`、`BLIND` 以及依赖 CAD 字体或控制码解析的 `⌀`、`Ø` 和 `%%c`。螺纹件首段直接使用从辅助字符串提取并规范化的 `thread_designation`，外径显式写为 `D`，例如通孔 `M3*D5.5-H12-THRU`、`M4x0.7*D6-H10-THRU`，盲孔 `M3*D5.5-H12-DP8`；不自动补充字符串中不存在的螺距或公差。非螺纹件首段使用模型测得并通过几何审计的内孔直径且显式写为小写 `d`，例如通孔 `d3*D5.5-H12-THRU`、盲孔 `d3*D5.5-H12-DP8`。通孔规格必须且只能以 `-THRU` 结尾；盲孔规格不得写 `BLIND`，必须以 `-DP深度` 结尾。`THRU` 与 `DP` 同时出现、两者都缺失、盲孔深度缺失或非正值均为无效规格；不得把非螺纹件内径改写成 `M…`。
2. 安装孔径、六面分布、逐件原始尺寸、接触侧及采购待确认信息保存在检查记录，不扩展类别表列。类别行、颜色和总数必须与逐件映射一致。
3. 默认不生成逐件坐标表。只有用户要求或图上位号无法唯一定位时才增加；定位点为安装孔中心，坐标基、单位、轴向、安装板外表面、柱身侧和安装接触面必须明确。排序不得改变位号；源实例和放置矩阵可留在检查记录，避免撑宽图面表格。
4. 可选表格的字号、列宽、行高、贴边、分列和碰撞规则全部执行[表格规范](notes-tables-titleblock.md)，无法同幅清楚容纳时按图幅流程处理，不拆第二张图幅或缩小文字。

## 6. 一致性与位置门禁

必须满足：

`图上唯一位号数 = 已确认独立压铆实例数 = 类别表总数 = 六侧计数合计`

还必须满足：

- 每个已确认实例恰好对应一个最终 DXF 锚点和一个位号，锚点 handle 与位号 handle 均唯一；最终 DXF 回读得到的 `STUD` 层全部位号必须与逐件记录集合完全相等，并位于各自目标视图边界内；

- 独立审计必须重新打开当前 STEP/STP，在新的 FreeCAD 文档中重新形成候选集合，独立推导安装板外表面、柱身方向、向内或向外状态和三维锚点；目标视图只能由安装板外表面确定，随后从 STEP 独立投影到最终 DXF 纸面坐标。不得读取生成器预填的候选集合、`exterior_side_confirmed`、`body_side_confirmed`、目标视图、期望纸面坐标或 `pass` 作为结论；

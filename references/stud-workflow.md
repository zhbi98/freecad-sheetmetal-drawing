# 压铆柱识别、分面与分类

本流程中的“卯柱”对应压铆柱/压铆件。所有实例、尺寸、类别、面和位号从当前 STEP 生成，不沿用旧图；表格外观统一由[表格规范](notes-tables-titleblock.md)维护。

## 1. 找出实例并测量

1. 展开装配树，区分钣金本体、装配容器/复合副本和独立零件，避免父子重复计数。本项目约定源名称含 `3D` 的零件进入压铆候选清单；导入器改名时追溯 STEP 实例关系。
2. 逐件确认其为独立实体，具有可测轴向外圆柱、内孔并与钣金安装位置对应。命中名称但几何损坏、内孔缺失或不接触时保留实例并列异常，不静默丢弃或编造尺寸。
3. 保存源标签/标识、放置矩阵、轴线、轴心、外径、内径、轴向总高和实体包络。总高是独立实体两端沿轴线的长度，不含板厚，也不是装配露出高度。
4. 外径取安装后柱身连续圆柱段，排除压入齿、倒角和头部/法兰；内径取有效孔圆柱段，排除入口倒角和局部沉孔，并记录盲孔深度。多个候选圆柱段、精度不足或非圆柱异形件先查确认资料，仍不明确则记录候选截面并标为待确认。

**产出：** 每个候选实例恰好一条逐件记录；关键几何或来源不明的实例不进入已确认分类。

## 2. 分开判定安装接触侧和柱身侧

1. 结合头部、法兰、压花/台阶、接触关系和确认资料识别压入/支承端。登记同一安装孔的两个孔口、面和法向；两个孔口属于同一通孔，不能因距离近就认定安装侧。孔中心取孔轴线与安装面的交点，并核对压铆轴线同心。
2. 压入/支承端实际贴合的钣金外表面定义**安装接触面/安装侧**。检查接触段、板厚和另一侧露出；面法向只描述已确认的面，不能单独决定安装侧。
3. 以安装孔局部板厚中面为分界，检查柱身连续主圆柱在板两侧的轴向范围；主段实际伸出的外侧定义**柱身所在侧**。头部、压花或嵌入板内短段不能代替主段。不得从安装面法向、全局坐标正负、最近孔口或 TOP/BOTTOM 名称推断柱身侧。
4. 安装接触侧与柱身侧可以相反，必须分别记录。柱身跨两侧、露出相近、折边/台阶复杂或装配干涉时使用隔离三维视图/剖视和零件资料核定；无法核定则待确认。
5. 先确定模型中的物理侧，再按绘图坐标基映射到 DRAWING 六方向中唯一的柱身侧视图。遮挡时可在同幅增加局部/剖视，但不得把位号换到相反主视图。

逐件证据链至少包含：源实例、安装孔及两孔口、轴线/孔心、安装接触面/法向/侧、柱身轴向范围/侧、目标视图、视向和位号。用至少三个不共线特征核对相反视图的镜像。

**产出：** 每个已标实例恰好属于一个柱身侧视图；六侧计数之和等于已确认实例数。计数相等不能代替逐件判面。

## 3. 分类、颜色和位号

1. 分类键为 `(柱体外径, 内径, 独立实体轴向总高度)`。优先比较确认的公称尺寸；否则使用未舍入模型值和记录的几何容差。显示小数位不是分类容差，任一项有实质差异即另分类。
2. 安装面、颜色、螺纹、源名称、数量和安装孔径不属于分类键。同一规格位于不同面仍属同类；边界不明、精度不足或内孔定义不明时不得强行合并。
3. 按稳定规则分配 A、B、C…及每类独有的高区分度颜色；视图和表格保持一致，并保留字母以支持黑白打印。
4. 同类位号为 `A1/A2…`。优先保留已核对源实例顺序；新编号时记录稳定坐标排序规则和坐标系。每个实例位号唯一，只在柱身侧视图的实际孔/柱中心附近出现一次。
5. 标记不得改变真实轮廓；密集处移动文字或使用引线，不让位号遮挡孔边和尺寸。

**产出：** `源实例 → 分类键 → 类别/颜色 → 位号 → 安装接触侧 → 柱身侧 → 图上坐标` 的完整映射。

## 4. 图面表格和可选坐标

1. 类别表为必需项，固定三列“类、规格、总数”。规格写作 `M<内径>*D<外径>-H<高度>`，使用大写 `M/D/H`、半角 `*` 和 `-`，去掉无意义尾零；例如 `M3*D5.5-H12`。`M` 是本项目规格前缀，不自动补充螺距或螺纹公差。
2. 安装孔径、六面分布、逐件原始尺寸、接触侧及采购待确认信息保存在检查记录，不扩展类别表列。类别行、颜色和总数必须与逐件映射一致。
3. 默认不生成逐件坐标表。只有用户要求或图上位号无法唯一定位时才增加；定位点为安装孔中心，坐标基、单位、轴向、所属柱身侧和安装接触面必须明确。排序不得改变位号；源实例和放置矩阵可留在检查记录，避免撑宽图面表格。
4. 可选表格的字号、列宽、行高、贴边、分列和碰撞规则全部执行[表格规范](notes-tables-titleblock.md)，无法同幅清楚容纳时按图幅流程处理，不拆第二张图幅或缩小文字。

## 5. 一致性门禁

必须满足：

`图上唯一位号数 = 已确认独立压铆实例数 = 类别表总数 = 六侧计数合计`

若输出坐标表，还须满足 `坐标表行数 = 已确认实例数`。逐件核对位号、类别、颜色、孔心、安装接触侧和柱身侧；任何差异停止交付，不得只调整汇总数字。

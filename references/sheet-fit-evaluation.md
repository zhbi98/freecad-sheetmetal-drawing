# 六视图图幅与比例评估

每个新 STEP 都重新评估。指定图幅时锁定图幅及方向；未指定时才比较项目允许的基本/加长图幅。六个主视图同幅、同一比例并保持固定第三角法拓扑。

## 1. 纸面占用模型

1. 从同一绘图坐标基取得六个未缩放投影包围框 `(w_i,h_i)`；不能仅以三维总包络代替实际投影。
2. 对候选统一比例 `s`，分别计算：
   - `W_geom/H_geom`：六个几何投影按固定布局后的并集；
   - `W_views/H_views`：加入视图名、尺寸、位号、引线和中心线端伸后的并集；
   - `W_all/H_all`：再加入技术要求、全部表格、标题栏和图框限制后的整图并集。
3. FRONT 是组中心锚点；TOP/FRONT/BOTTOM 共享竖向投影基准，LEFT/FRONT/RIGHT/REAR 共享横向基准。验收：`x_LEFT < x_FRONT < x_RIGHT < x_REAR`、`y_BOTTOM < y_FRONT < y_TOP`、`x_TOP=x_FRONT=x_BOTTOM`、`y_LEFT=y_FRONT=y_RIGHT=y_REAR`。基准取同一模型点的投影，不用轮廓包围框中心。
4. 每对相邻视图根据两侧尺寸、位号、引线和安全空白计算最小净距 `G_req`；实际净距从该值起算。若 `G_actual > 1.25×G_req + h_text`，必须有可复核避让原因，否则收紧。
5. 图框可用区扣除模板规定的装订边、图框边距和不可绘区。类别表、版本履历、标题栏及可选表格按[表格规范](notes-tables-titleblock.md)的实际紧凑外包络和贴边位置参与碰撞；不得用宽松占位框迫使视图缩小。

## 2. 求最高可行统一比例

1. 在固定六视图拓扑、贴边表格和全部纸面字高不变的条件下，求连续上限 `s_fit`：刚好满足图框边界、对象碰撞、最小净距和打印可读性的最大比例。
2. 从项目允许比例序列中选不大于 `s_fit` 的最高档 `s_sel`；同时记录下一档更大比例及首个失败约束。下一档实际也能通过，当前候选即失败。
3. 指定图幅/方向时只在该图幅内求 `s_fit/s_sel`，不得改换图幅或为追求固定占用率降低比例。指定比例时还须验证该比例；无法容纳则报告失败，不暗改打印比例。
4. 未指定图幅时，对每个允许图幅使用其最高可行比例；在视图纸面尺寸和阅读性相当时优先较小图幅，仍相当时选择视图更大且净距更接近 `G_req` 的候选。

`R_view=max(W_geom/W_use,H_geom/H_use)` 和 `R_all=max(W_all/W_use,H_all/H_use)` 只用于记录异常，不是缩小视图的目标。贴边表格可使 `R_all=1.0`；只要实体不越界即可。若 `R_view<0.65`，记录为何不能继续收紧间距或提高比例；细长模型另记录长宽比和各视图纸面尺寸。禁止为接近 `0.80` 主动缩小视图。

## 3. 候选通过条件

候选必须同时满足：

- 六个主视图及全部尺寸、位号、引线、说明、表格和标题栏位于图框可用区；
- 第三角法顺序、共同投影基准和统一比例未改变；
- 视图/标注外包络互不重叠，实际净距不小于 `G_req`；
- 所用 `s_sel` 是当前图幅最高允许比例，下一档失败原因可复算；
- 表格贴边、文字格高及安全边距通过专项验收；
- 在 100%/声明比例预览中，小孔、最窄间隙、相邻线、尺寸文字、箭头、中心标记和线型可辨；
- 图框、标题栏比例和打印设置一致，无裁切或自动缩放。

六视图组只能整体平移、统一缩放和沿投影方向调整净距；禁止交换/旋转视图、自由网格、移动固定角区、单独缩放、压缩字高或把间距降到 `G_req` 以下。

## 4. 两阶段评估和失败处理

1. **预评估：** 六个裸投影生成后，连同预估尺寸、位号、技术要求、实际表格和标题栏筛除明显不足候选。
2. **终评估：** 全部 CAD 实体生成后，从实际文字和几何外包络重新计算 `s_fit/s_sel`、净距、碰撞和打印可读性。任何字体、文字换行、尺寸、位号、表格、标题栏或图幅变化都重做终评估。
3. 固定图幅在最小允许且可读比例下仍失败时，停止交付并报告可用区、所需范围、超出方向/数值、测试比例和可通过的图幅建议；不得裁切或拆页。
4. 未固定图幅且最大允许图幅仍失败时，报告最小纸面需求和限制项，等待工程决定。

## 5. 评估记录

保存：绘图基准、六个原始投影框、候选图幅/方向、`s_fit/s_sel`、下一档失败约束、FRONT 锚点、投影基准坐标、`G_req/G_actual`、各视图纸面宽高、表格/说明/标题栏外包络、贴边偏差、字形/格高比、`W_geom/H_geom`、`W_views/H_views`、`W_all/H_all`、`R_view/R_all`、最小剩余净距、打印可读性和选择理由。

终评估数据必须来自最终 DXF 回读实体和实际比例预览；脚本估算、FreeCAD 截图或“文件已生成”不能代替。

**通过条件：** 图幅、标题栏和打印设置一致；比例是全部约束下最高允许统一比例；表格贴边紧凑；六视图和全部标注完整、清晰、无碰撞或裁切，且不存在仍可通过提高比例或收紧无依据间距放大的情况。

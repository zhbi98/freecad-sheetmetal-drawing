# 六视图 1:1 图幅评估

每个新 STEP 都重新评估。六个主视图和必要补充视图固定按模型空间 `1:1` 绘制；图幅只能在 A4～A0 基本幅面和 A0 加长幅面中选择，不得通过缩小视图适配图幅。

## 1. 纸面占用模型

1. 从同一绘图坐标基取得六个未缩放投影包围框 `(w_i,h_i)`；模型毫米直接等于图上毫米，不能仅以三维总包络代替实际投影。
2. 分别计算：
   - `W_geom/H_geom`：六个 `1:1` 几何投影按固定布局后的并集；
   - `W_views/H_views`：加入视图名、尺寸、位号、引线和中心线端伸后的并集；
   - `W_all/H_all`：再加入技术要求、全部表格、标题栏和图框限制后的整图并集。
3. FRONT 是组中心锚点；TOP/FRONT/BOTTOM 共享竖向投影基准，LEFT/FRONT/RIGHT/REAR 共享横向基准。验收：`x_LEFT < x_FRONT < x_RIGHT < x_REAR`、`y_BOTTOM < y_FRONT < y_TOP`、`x_TOP=x_FRONT=x_BOTTOM`、`y_LEFT=y_FRONT=y_RIGHT=y_REAR`。基准取同一模型点的投影，不用轮廓包围框中心。
4. 每对相邻视图根据两侧尺寸、位号、引线和安全空白计算最小净距 `G_req`；实际净距从该值起算。若 `G_actual > 1.25×G_req + h_text`，必须有可复核避让原因，否则收紧。
5. 图框可用区扣除模板规定的装订边、图框边距和不可绘区。类别表、版本履历、标题栏及可选表格按[表格规范](notes-tables-titleblock.md)的实际紧凑外包络和贴边位置参与碰撞；不得用宽松占位框迫使图幅升级。

## 2. 标准图幅选择

基本幅面尺寸固定为：A4 `210×297 mm`、A3 `297×420 mm`、A2 `420×594 mm`、A1 `594×841 mm`、A0 `841×1189 mm`。每档均允许整体旋转，不改变固定六视图拓扑。

1. 按 A4 → A3 → A2 → A1 → A0 顺序评估两个方向，选择能够容纳 `W_all/H_all` 且全部门禁通过的最小幅面；同一幅面的两个方向都通过时，选择无依据留白更少、净距更接近 `G_req` 的方向。
2. 所有候选的视图比例均固定为 `scale=1.0`（标题栏写 `1:1`）；不得设置其他比例、整体缩放六视图或用打印缩放改变交付几何。表格和文字属于纸面注释，不受模型几何 `1:1` 的固定字号约束，必须按第 4 节的可读性系数计算。
3. 选定图幅前的所有更小基本幅面必须有可复算的失败约束；更小幅面实际能够通过时，当前选择失败。
4. 不接受用指定较大幅面跳过最小档验证，也不接受锁定较小幅面后降低比例。用户指定方向时只限制候选方向，仍按相同顺序选择最小可行档；该方向下 A0 不足时进入 A0 加长流程。

## 3. A0 加长幅面

1. A0 两个方向均失败后才允许进入 A0 加长幅面，记录 `sheet_class=a0_extended`、`sheet=A0xN` 和整数 `a0_extension_n=N`。
2. 本 Skill 的无模板回退序列定义为 `1189×(841×N) mm`，`N≥2`，允许整体旋转；按 `N=2,3,…` 选择能够通过全部门禁的最小档。项目或加工厂已确认其他 A0 加长系列时可整体覆盖该尺寸序列，但必须记录模板来源和每档实测尺寸。
3. A0 加长只扩大一个方向，另一边固定为 `1189 mm`。若内容在两个旋转方向的固定边都超过可用范围，则停止交付并报告所需最小宽高；不得改成任意自定义图框、缩放视图、裁切或拆页。
4. A0 加长仍是单一图幅，六个主视图继续保持固定布局和 `1:1`；不得把它解释成局部放大图、分页或多个拼接 DXF。

## 4. 图幅驱动的文字与表格可读性

1. 对候选图幅取最终纸面长边 `L`、短边 `S`，计算 `k_r=clamp(sqrt(max(L/297,S/210)),1.0,3.0)`。为消除 ISO 舍入边长引入的微小漂移，A4、A3、A2、A1、A0 标准尺寸分别固定采用理论倍率 `1.0、2^0.25、√2、2^0.75、2.0`；A0 加长或已确认的非标准模板尺寸仍按公式计算。该系数只用于纸面注释及其布局，不得乘到 HLR 投影、特征坐标、尺寸定义点或测量值上。
2. 正文、表头、标签、值、视图名、压铆位号、补充视图标签和尺寸文字的最低字高为 `3.5×k_r mm`；表名、技术要求标题和主要图样名称的最低字高为 `4.0×k_r mm`。例如 A4 的 `k_r=1.0`，A0 的 `k_r=2.0`，对应最低字高分别为 `3.5/4.0 mm` 和 `7.0/8.0 mm`。
3. 字号变化后，按最终字体真实字形重新计算表格行高、列宽、合并区、内边距、技术要求行距、尺寸文字净距和引线避让；禁止只增大文字而保留旧网格，也禁止把整个表格作为块做非 1 倍缩放。表格仍应紧凑贴边，不能用放大后的空单元格挤压视图。
4. 图幅和 `k_r` 相互影响，必须迭代：以候选图幅计算 `k_r` → 重排全部注释、尺寸样式和表格 → 从重排结果重算 `W_all/H_all` → 重新选择最小图幅。只有连续两次得到相同图幅、方向和 `k_r`，且两轮 `W_all/H_all` 均不超过各自记录的可用区，才算稳定；超过 10 次仍不稳定则停止并报告，不得取较小字号强行通过。
5. `selected` 必须记录 `readability_basis=standard_a_series_theoretical_else_sqrt_max_normalized_a4_span_clamped_1_to_3`、`readability_scale`、`body_text_min_mm`、`major_text_min_mm`、`dimension_text_min_mm`、`dimension_arrow_min_mm` 和 `dimension_text_gap_min_mm`。这些值由 `scripts/readability_scale.py` 独立复算，不接受生成器自行声明通过。

## 5. 候选通过条件

候选必须同时满足：

- 六个主视图、必要补充视图及全部尺寸、位号、引线、说明、表格和标题栏位于图框可用区；
- 第三角法顺序和共同投影基准未改变，全部视图与尺寸定位几何均为 `1:1`；
- 视图/标注外包络互不重叠，实际净距不小于 `G_req`；
- 所用幅面是当前规则下最小可行档，前一档失败原因可复算；
- 表格贴边、动态最低字高、文字格高及安全边距通过专项验收；
- 在 100% 预览中，小孔、最窄间隙、相邻线、尺寸文字、箭头、中心标记和线型可辨；
- 图框、标题栏比例和打印设置一致，无裁切或自动缩放。

六视图只能整体平移和沿投影方向调整必要净距；禁止交换、旋转单个视图、自由网格、移动固定角区、整体或单独缩放、压缩字高，或把间距降到 `G_req` 以下。

## 6. 两阶段评估和失败处理

1. **预评估：** 六个裸 `1:1` 投影生成后，连同预估尺寸、位号、技术要求、实际表格和标题栏筛除明显不足候选。
2. **终评估：** 全部 CAD 实体生成后，从实际文字和几何外包络重新选择最小可行图幅，复算净距、碰撞和打印可读性。任何字体、文字换行、尺寸、位号、表格、标题栏或图幅变化都重做终评估。
3. A0 加长序列仍无法通过时，报告图框可用区、最小纸面需求、超出方向/数值和限制项，等待工程决定；不得裁切、拆页或降低比例。

## 7. 评估记录

保存：绘图基准、六个原始投影框、`geometry_scale=1.0`、候选幅面/方向/尺寸、前一档失败约束、A0 加长档数及模板来源（如适用）、FRONT 锚点、投影基准坐标、`G_req/G_actual`、各视图纸面宽高、表格/说明/标题栏外包络、贴边偏差、字形/格高比、`W_geom/H_geom`、`W_views/H_views`、`W_all/H_all`、最小剩余净距、打印可读性和选择理由。

根级 `selection_iterations` 必须逐轮保存 `iteration/sheet/sheet_class/orientation/size_mm/readability_scale/layout_recomputed/usable_size_mm/w_all_mm/h_all_mm/candidate_fits`；轮次从 1 连续编号，`layout_recomputed=true` 只能在使用该轮 `k_r` 完成重新排版后写入，`candidate_fits=true` 只能在该轮 `W_all/H_all` 均落入 `usable_size_mm` 后写入。根级 `selection_stability` 固定记录 `max_iterations=10`、`required_consecutive_matches=2`、`completed_iterations`、`stable_consecutive_matches` 和 `stable`。验收脚本必须独立核对历史长度为 `2～10`、最后两轮签名与 `selected` 一致、连续稳定数真实；`dxf_text_audit.py` 还须从最终 DXF 排除 `BORDER` 后重算内容外包络，并确认其宽高与最后两轮 `W_all/H_all` 一致。禁止只写 `selected.pass=true` 或伪造外包络代替迭代证据。

`selected` 至少包含 `sheet`、`sheet_class`、`orientation`、`size_mm`、`scale=1.0`、`geometry_scale=1.0`、`readability_basis`、`readability_scale`、正文/主标题/尺寸文字/箭头/尺寸文字净距五项最低值、`previous_candidate_failure` 和 `pass`；A0 加长时另含 `a0_extension_n`。选择 A4 时 `previous_candidate_failure=null`；其他档须记录紧邻前一档的名称及非空 `failed_constraints`。终评估数据必须来自最终 DXF 回读实体和 100% 预览；脚本估算、FreeCAD 截图或“文件已生成”不能代替。

**通过条件：** 全部视图及尺寸几何为 `1:1`；选中的 A4～A0 或最小 A0 加长档与记录尺寸一致；前一档确实不能通过；表格贴边紧凑；六视图和全部标注完整、清晰、无碰撞或裁切。

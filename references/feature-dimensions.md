# 特征尺寸标注清单

本清单用于从**当前 STEP**建立六视图的尺寸覆盖。TOP、BOTTOM、FRONT、REAR、LEFT、RIGHT 六个主视图都必须有尺寸表达：至少标注该视向下有意义的水平/垂直总尺寸，边视图则标注总长、总高、板厚或折边高度等可见尺寸。普通孔、长圆孔、异形开口、台阶、折边和压铆安装特征须在表达真形且最清楚的视图中标注规格与必要定位；不要求把同一尺寸在相反视图重复，也不把所有可测边线标满。尺寸值必须从源几何或已确认设计资料取得，公差、螺纹等级、折弯展开和工艺参数不能从外形猜测。

## 逐类确定几何尺寸与位置

| 特征 | 几何/规格应标 | 定位及图幅安排 |
| --- | --- | --- |
| 六面轮廓与钣金 | 必标成形件三方向总宽、总深、总高及可确认的板厚 `t`；每个主视图至少具有与该视图对应的总尺寸、厚度或折边高度尺寸。 | 六个主视图都保留正常正投影；同一物理总尺寸优先在最清楚的视图标一次，其他视图仍须有本视向独有的尺寸表达。 |
| 安装面、台阶与折边 | 相对基准的安装面高度/标高、关键面间距、折边高度或伸出量；模型可确认时标内弯 `R` 与折弯角。 | 在侧视/剖视上指明测量的是哪两个面；多安装面列高度明细。展开尺寸、折弯扣除和 K 因子缺设计资料时列为待确认。 |
| 功能性圆孔 | 项目要求标注时使用原生直径尺寸 `⌀d`，若为盲孔则按确认资料标深度；不自动附加孔数或 `THRU`。螺纹规格只在模型属性或设计资料能确认时写入。 | 孔心定位仅在加工所需或用户明确要求时从稳定基准表达；必要时加中心标记。 |
| 普通圆孔 | 不自动生成 `n×⌀d THRU` 成组引线。用户或项目模板要求孔径时，在孔呈真圆的视图使用原生直径 `DIMENSION` 标注 `⌀d`。 | 不另建普通孔明细表，也不因 STEP 中存在圆孔就自动铺满孔径、数量或通孔文字。 |
| 用户指定的重要圆孔组 | 只有用户明确指定数量表达时才使用 `n×⌀d`；`THRU` 仅在项目模板明确要求且源几何可确认时增加。 | 引线只指向一个明确的代表孔，并避开邻近轮廓和尺寸；未指定时不生成该类成组标注。 |
| 长圆孔 | 总长、宽度及端部半径 `R=宽度/2`（若实际几何满足）；相同长圆孔注明数量。总长与两端圆心距不能混写。 | 在真形视图上定位中心或对称轴；孔组可给首孔位置与中心距，其余位置由表格或清晰尺寸链确定。 |
| 圆角矩形孔与异形开口 | 外包络长/宽、相同圆角半径与数量；异形轮廓还须给制造所需的直线段、圆弧、角度或认可的轮廓数据。 | 从统一基准定位开口中心或确定轮廓的功能边；半径引线指向对应圆弧。仅有外包络而不能唯一确定异形轮廓时，先补轮廓数据；仍无法表达时按下述门禁增加可追溯局部图。 |
| 沉孔、锥形沉孔与台阶孔 | 通孔/内孔 `⌀d`，入口大径 `⌀D`；锥形沉孔给夹角，平底台阶孔给深度，必要时说明入口侧及数量。 | 优先在可见入口侧用引线指向正确孔；只有内部形状无法唯一表达时才按下述门禁使用剖视/局部图。侧壁孔给所属面与独立定位坐标，孔的两侧形状不得混写。 |
| 压铆柱与安装孔 | 分类表固定为“类、规格、总数”三列。分类键包含内径、外径、从压铆进入背面到柱体自由端且包含安装处局部板厚的安装总高度、孔型、适用的盲孔深度、加工孔类型及螺纹件的规范化螺纹规格。分类高度 `H = 柱身侧露出量 + 局部板厚`，并须与两基准面直接距离一致；不能用独立实体总长代替，也不能重复加板厚。孔型与螺纹需求是独立分类轴，螺纹通孔、螺纹盲孔、光孔通孔和光孔盲孔均为合法组合，严禁互相推断。与实例关联的非空辅助字符串中包含有效 `M…` 螺纹规格即表示需要螺纹，规格如 `M3*D5.5-H12-THRU`；字符串不含有效螺纹规格即表示不需要螺纹，规格使用实际内孔直径，如 `d3*D5.5-H12-THRU`；螺纹盲孔写作 `M3*D5.5-H12-DP8`，非螺纹盲孔写作 `d3*D5.5-H12-DP8`。类别表规格串只使用 ASCII 兼容的 `d/D/H/DP/THRU`，其中小写 `d` 表示光孔内径、大写 `D` 表示柱体外径、`H` 表示上述安装总高度；通孔必须且只能带 `THRU`，盲孔必须且只能带 `DP深度`，不得出现 `BLIND`。`THRU/DP` 同时出现或同时缺失均无效。不使用 `ID/OD`、`⌀`、`Ø` 或 `%%c`。相同几何尺寸但有/无螺纹不同必须分为不同类别。安装孔径、六面分布和逐项原始尺寸保存在检查记录中，不拆成图面列；辅助文字没有给出的螺距、螺纹公差等信息不得补写。 | 只在安装板外表面对应的六视图中使用颜色字母和唯一位号，相反视图不重复；柱身向内部延伸也不改变目标视图。核对压铆件轴线与安装孔轴线同心，并从卯柱自身实体拓扑确认通孔/盲孔，不能用钣金安装孔代替。孔型只由实体拓扑确认，螺纹需求只由有效辅助字符串确认；辅助文字只参与识别和分类，绘图副本须抑制其字形。默认不出逐件坐标表；只有用户明确要求或图上位号无法唯一定位时才增加基准尺寸/坐标。单侧露出高度和独立实体总长均不直接作为分类高度。 |

## 局部图、剖视和辅助视图门禁

1. 默认策略为 `main_views_only_unless_traceable_and_necessary`：没有必要性证据时，`supplementary_view_validation` 必须记录 `declared_count=0`、`per_view=[]`、`pass=true`。不得因自动识别到孔组、压铆件、空白区域、标签拥挤或版面尚有空间而自动产生 `Kxx/Pxx/Sxx` 小图。
2. 增加补充视图前，必须依次尝试主视图直接标注、调整标注落点、增大标准图幅和在可读范围内统一改变六视图比例。仅当仍存在“隐藏结构不能唯一标注、非真形特征必须给真形、内部结构必须剖开、已尝试布局后主视图仍无法无歧义表达”之一时才允许增加；原因分别记录为 `hidden_feature_not_unambiguously_dimensionable`、`non_true_shape_feature`、`internal_feature_requires_section` 或 `main_view_annotation_congestion_after_layout_attempts`。
3. 每个补充视图在来源主视图上必须具有明确的来源边界或剖切线、观察/剖切箭头和编号；补充视图标题必须重复相同编号并给出比例。来源编号与标题编号是两个不同文字实体，缺一不可；仅在小图上写 `K01/P01` 不构成可追溯关系。
4. 每项 `supplementary_view_validation.per_view` 至少记录：`id`、`kind`、`necessity_reason`、`source_feature_ids`、`source_main_view`、`source_transform_id`、`projection_transform_id`、`source_bounds_sheet_mm`、`view_bounds_sheet_mm`、`view_direction_3d`、`scale`、`source_label_handle`、`title_label_handle`、`source_boundary_handles`、`direction_arrow_handles`、`geometry_handles`、`dimension_handles` 和 `pass`。编号只使用 `Knn/Pnn/Snn`，全图唯一；范围、方向、比例、STEP 特征或任一实体 handle 缺失均失败。
5. 最终 DXF 回读后，`feature_annotation_audit.py` 必须确认所有登记 handle 存在，来源标签与标题标签严格成对，登记标签集合与实际 `SUPPLEMENTARY_LABEL` 或 `Kxx/Pxx/Sxx` 标签集合完全一致。任何未登记、重复、过期或只有标题没有来源的标签均失败。补充视图不能替代六个主视图、不能移动压铆位号到非安装板外表面，也不能成为绕过主视图尺寸覆盖的手段。

## 标注步骤与验收

1. 先为六个视图分别建立尺寸清单，记录水平/垂直总尺寸、板厚/折边高度和项目要求表达的孔、槽、开口、台阶及压铆特征。再为每个尺寸保存源对象/几何标识、测量基准、未舍入模型值、显示值、符号、所属面和目标视图；普通孔清单用于核对，不等于必须自动生成图面孔标。
2. 对重复特征逐个比对尺寸与位置。默认不合并成 `n×⌀D THRU` 引线；只有用户或项目模板明确要求数量表达时，才合并同规格、同加工属性的孔。若使用尺寸链，逐段求和核对，避免同时给出相互矛盾的闭合链。
3. 线性和角度尺寸使用原生可编辑 DXF `DIMENSION` 实体并引用统一 `DIMSTYLE`；尺寸界线从被测特征引出，尺寸线在两界线之间连续，空间足够时两端使用朝内的闭合实心箭头，尺寸文字置于尺寸线上方并与其保持净距。空间不足时可按尺寸样式把箭头或文字移到外侧，但不得改用斜线端头、字符箭头或独立 `LINE/TEXT` 拼接。直径、半径和孔标注优先使用相应尺寸实体；必须用引线时采用可编辑 `LEADER/MLEADER` 并保留 `⌀/R` 等性质符号。
4. 放置标注后核对箭头是否落在目标特征、尺寸界线是否避开邻孔、数字与符号是否完整显示。标注区域拥挤时把成组注释移至空白区、增大标准图幅或统一降低六图比例；只有通过上述门禁后才可在同一图幅增加补充视图，不得拆分六个主视图，也不能靠缩小文字解决。
5. 逐视图形成 `dimension_validation.per_view` 记录，至少包含 `required_features`、`dimension_entities`、`missing`、`model_comparison` 和 `pass`。六个视图键必须齐全，每个视图至少有一个有效尺寸实体且 `missing=[]`；每个显示值按未舍入模型值和统一舍入规则回算，符号与被标特征类型一致。另存 `dimension_validation.style_validation`，至少记录预期/实际 `DIMENSION` 数量、所用 `DIMSTYLE`、闭合实心箭头、尺寸界线、文字位置、手工拼接尺寸数量和结论；手工拼接数量必须为零。还须建立 `feature_annotation_validation`：逐个物理孔/槽记录源几何、尺寸、所属轴向、真形视图、组号和组内数量，且明确 `annotation_policy=no_automatic_grouped_callout`、`displayed_group_callouts=0`。圆孔必须合并同轴、同心、同轴向区间的拆分圆柱面后再计数，不能按面数计孔数。最终 DXF 用 `scripts/feature_annotation_audit.py` 在新 FreeCAD 文档中重新读取当前 STEP，独立重建圆孔清单，核对 STEP/DXF 哈希，并确认 `FEATURE_CALLOUT` 中不存在自动成组孔标实体；生成器自报结论不能单独通过。长圆孔、矩形孔和异形开口仍须逐项保存在清单中并由人工 M02 对照预览复核。缺失项目要求尺寸、错误视图、引线指错、重复约束、闭合尺寸链矛盾、样式不合格或模型回算不一致均判失败。
6. 逐项勾对压铆清单：每个实例只在正确的一个六视图中有唯一位号，分类表与图上数量一致；逐件孔型必须为已确认的 `through` 或 `blind`，类别键和规格后缀必须匹配，通盲不同不得共用类别。无柱面的视图不出现压铆位号，但仍须标注该视图的外形、厚度/高度或独有特征尺寸。缺少由设计决定的采购参数时保留待确认；尺寸覆盖通过不等于折弯展开、公差和工艺信息已经获批。
7. 验收发现漏标时，先确认缺失特征、所属视图、尺寸来源和落点均可从 STEP 唯一确定，且现有尺寸回算、符号、编号和位置均已通过。满足这些条件时只补缺失的原生 `DIMENSION` 或孔标/引线，已有正确标注保持不变；补标后重新做碰撞、尺寸链、模型回算和连续闭环检查。若缺项来自特征识别、视图映射或基准错误，则不属于单纯漏标，必须修正相应上游逻辑。

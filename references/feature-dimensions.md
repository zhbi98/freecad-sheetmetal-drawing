# 特征尺寸标注清单

本清单用于从**当前 STEP**建立六视图的尺寸覆盖。TOP、BOTTOM、FRONT、REAR、LEFT、RIGHT 六个主视图都必须有尺寸表达：至少标注该视向下有意义的水平/垂直总尺寸，边视图则标注总长、总高、板厚或折边高度等可见尺寸。普通孔、长圆孔、异形开口、台阶、折边和压铆安装特征须在表达真形且最清楚的视图中标注规格与必要定位；不要求把同一尺寸在相反视图重复，也不把所有可测边线标满。尺寸值必须从源几何或已确认设计资料取得，公差、螺纹等级、折弯展开和工艺参数不能从外形猜测。

## 逐类确定几何尺寸与位置

| 特征 | 几何/规格应标 | 定位及图幅安排 |
| --- | --- | --- |
| 六面轮廓与钣金 | 必标成形件三方向总宽、总深、总高及可确认的板厚 `t`；每个主视图至少具有与该视图对应的总尺寸、厚度或折边高度尺寸。 | 六个主视图都保留正常正投影；同一物理总尺寸优先在最清楚的视图标一次，其他视图仍须有本视向独有的尺寸表达。 |
| 安装面、台阶与折边 | 相对基准的安装面高度/标高、关键面间距、折边高度或伸出量；模型可确认时标内弯 `R` 与折弯角。 | 在侧视/剖视上指明测量的是哪两个面；多安装面列高度明细。展开尺寸、折弯扣除和 K 因子缺设计资料时列为待确认。 |
| 功能性圆孔 | 孔径 `⌀d`，若为盲孔则深度；同规格重复孔说明数量。螺纹规格只在模型属性或设计资料能确认时写入。 | 孔心按共同原点给 X/Y（侧壁孔按适用坐标面给 X/Y/Z），或给从基准边到首孔、节距/末孔的受控尺寸链；必要时加中心标记。 |
| 普通圆孔 | 标注孔径 `⌀d`；相同规格、相同加工属性的孔可写 `n×⌀d`。不同直径、不同面或不同孔型不得合并。 | 在孔呈真圆的视图标注，并从稳定基准边/基准面给出能够唯一定位孔心或孔组的尺寸；默认不另建普通孔明细表。 |
| 用户指定的重要圆孔组 | 一处 `n×⌀d` 成组引线；等距时注明孔数、节距及适用的首孔定位，非等距时不得套用节距注法。 | 图上给孔心标记；完整定位图中的逐孔坐标仍在表中。引线只指向其中一个代表孔，不与相邻特征标注挤在一起。 |
| 长圆孔 | 总长、宽度及端部半径 `R=宽度/2`（若实际几何满足）；相同长圆孔注明数量。总长与两端圆心距不能混写。 | 在真形视图上定位中心或对称轴；孔组可给首孔位置与中心距，其余位置由表格或清晰尺寸链确定。 |
| 圆角矩形孔与异形开口 | 外包络长/宽、相同圆角半径与数量；异形轮廓还须给制造所需的直线段、圆弧、角度或认可的轮廓数据。 | 从统一基准定位开口中心或确定轮廓的功能边；半径引线指向对应圆弧。仅有外包络而不能唯一确定异形轮廓时，增加局部图/轮廓数据并标出未定义项。 |
| 沉孔、锥形沉孔与台阶孔 | 通孔/内孔 `⌀d`，入口大径 `⌀D`；锥形沉孔给夹角，平底台阶孔给深度，必要时说明入口侧及数量。 | 在可见入口侧或剖视/局部图用引线指向正确孔；侧壁孔给所属面与独立定位坐标。孔的两侧形状不得混写。 |
| 压铆柱与安装孔 | 分类表固定为“类、规格、总数”三列；规格写作 `M<内径>*D<外径>-H<高度>`，例如 `M3*D5.5-H12`，其中高度为独立实体总高度且不含板厚。安装孔径、六面分布和逐项原始尺寸保存在检查记录中，不拆成图面列；采购螺距、螺纹公差等未经确认的信息不写入分类表。 | 只在柱身实际所在侧对应的六视图中使用颜色字母和唯一位号，相反视图不重复；核对压铆件轴线与安装孔轴线同心。默认不出逐件坐标表；只有用户明确要求或图上位号无法唯一定位时才增加基准尺寸/坐标。总成露出高度不作为分类高度。 |

## 标注步骤与验收

1. 先为六个视图分别建立尺寸清单，记录水平/垂直总尺寸、板厚/折边高度和该视图负责表达的孔、槽、开口、台阶及压铆特征。再为每个尺寸保存源对象/几何标识、测量基准、未舍入模型值、显示值、符号、数量、所属面和目标视图；普通孔默认在图上标尺寸，但不另建明细表。
2. 对重复特征逐个比对尺寸与位置，只有确实同规格才合并为 `n×` 标注。计算首孔、孔距及末孔与总体尺寸的关系；若使用尺寸链，逐段求和核对，避免同时给出相互矛盾的闭合链。
3. 线性和角度尺寸使用原生可编辑 DXF `DIMENSION` 实体并引用统一 `DIMSTYLE`；尺寸界线从被测特征引出，尺寸线在两界线之间连续，空间足够时两端使用朝内的闭合实心箭头，尺寸文字置于尺寸线上方并与其保持净距。空间不足时可按尺寸样式把箭头或文字移到外侧，但不得改用斜线端头、字符箭头或独立 `LINE/TEXT` 拼接。直径、半径和孔标注优先使用相应尺寸实体；必须用引线时采用可编辑 `LEADER/MLEADER` 并保留 `⌀/R` 等性质符号。
4. 放置标注后核对箭头是否落在目标特征、尺寸界线是否避开邻孔、数字与符号是否完整显示。标注区域拥挤时把成组注释移至空白区、增大标准图幅或统一降低六图比例；可在同一图幅加局部图，但不得拆分六个主视图，也不能靠缩小文字解决。
5. 逐视图形成 `dimension_validation.per_view` 记录，至少包含 `required_features`、`dimension_entities`、`missing`、`model_comparison` 和 `pass`。六个视图键必须齐全，每个视图至少有一个有效尺寸实体且 `missing=[]`；每个显示值按未舍入模型值和统一舍入规则回算，符号与被标特征类型一致。另存 `dimension_validation.style_validation`，至少记录预期/实际 `DIMENSION` 数量、所用 `DIMSTYLE`、闭合实心箭头、尺寸界线、文字位置、手工拼接尺寸数量和结论；手工拼接数量必须为零。缺失尺寸、错误视图、引线指错、重复约束、闭合尺寸链矛盾、样式不合格或模型回算不一致均判失败。
6. 逐项勾对压铆清单：每个实例只在正确的一个六视图中有唯一位号，分类表与图上数量一致；无柱面的视图不出现压铆位号，但仍须标注该视图的外形、厚度/高度或独有特征尺寸。缺少由设计决定的采购参数时保留待确认；尺寸覆盖通过不等于折弯展开、公差和工艺信息已经获批。

# 投影简化与 DXF 复杂度控制

本规则只负责从源 STEP 得到几何等价、分层正确且不过度碎片化的六视图投影；最终 DXF 回读和目标 CAD 测试由 [DXF 交付规则](dxf-delivery.md)负责。

## 1. 源模型与绘图副本

1. 源 STEP 只读保留；识别、测量、分类和压铆分面均以源模型为依据。建立 `源实例 → 简化实例 → 六视图实体` 映射。
2. 压铆件完成原始测量后，绘图副本可抑制滚花、实体螺纹、装饰沟槽、无功能微小圆角/倒角和导入缝线；必须保留轴线、安装位置、柱体外径、内孔、独立实体高度、头部/法兰控制轮廓和接触关系。
3. 钣金本体保留外轮廓、功能孔槽、异形开口、折边及影响投影视形或尺寸的圆角。只抑制纯切向边、光顺分界、导入缝线和无功能过渡边；小闭环不得仅因尺寸小而删除。
4. 简化前后比较包围框、装配位置、轴线、孔心、压铆分类尺寸、安装面和全部标注基准；超出记录的几何容差即回退。

## 2. HLR 输出

1. 六视图对绘图副本执行消隐；测量仍引用源模型。默认关闭无助于形状理解的平滑边、切线边、等参线和缝线，必要功能边按白名单恢复。
2. 必须按当前 FreeCAD 接口的完整返回结构取边，禁止只取固定的单个可见组和单个隐藏组。FreeCAD 1.1 的 `TechDraw.projectEx()` 返回 `[V, V1, VN, VO, VI, H, H1, HN, HO, HI]`：分别表示可见/隐藏的硬边、光顺边、轮廓分类、表观轮廓和等参线。逐组枚举、判空和计数；升级 FreeCAD 后必须重新读取接口文档并验证分组，禁止沿用未验证索引。
3. 默认工程视图按 FreeCAD 自身 DXF 视图导出逻辑保留 `V/VO/H/HO`，即硬边与表观轮廓；`V1/VN/VI/H1/HN/HI` 默认过滤。只有源特征清单证明某条制造功能轮廓依赖被过滤组时，才按具体源对象和边恢复，禁止把整组无条件打开。逐组保存原始数量、启用/过滤状态和理由。
4. 可见边进入 `VISIBLE`，被遮挡但需表达的真实边进入 `HIDDEN`，轴线进入 `CENTER`。先按几何键跨图层比较：完全重合时删除隐藏副本；部分重合时在交点/端点切分隐藏边，只保留真正被遮挡且不与可见边重合的区间。隐藏线先写入、可见线最后写入，保证阅读器绘制顺序也不会让虚线盖住实线。可见性转换点必须保留。
5. 每个视图记录 10 个原始 HLR 分组的返回数量、判空结果、过滤数量和最终归属，同时记录跨可见/隐藏重合的删除/切分数量、可见/隐藏实体、圆弧/圆、折线顶点、样条和源对象贡献排行。先处理滚花、螺纹和过渡边等高贡献来源，不在原因不明时全局删线。
6. 从源 STEP 建立逐视图功能特征清单，至少包含外轮廓、内孔、长圆孔、开口、折边、压铆件外径/内孔/法兰轮廓及其遮挡状态。清单中的内部特征必须在可见或隐藏结果中找到闭合轮廓或可解释的可见性分段；缺失时先检查 HLR 分组映射和简化副本，不得靠补画猜测轮廓。

## 3. 去碎片顺序

所有操作限定在同一视图、图层、线型和可见性类别内。容差由几何内核精度、图纸比例和打印分辨能力共同确定，且小于需保留的最小孔、槽宽、间隙和定位差。

1. 对绘图副本做拓扑精炼（如 `removeSplitter()`），先验证功能闭环和标注基准未变。
2. HLR 离散结果删除连续重复点、零长度段和同组精确重复实体；可见段与隐藏段重合时只在重合区保留可见段。
3. 仅在端点唯一成对且节点不是分支、交点、拐点、特征边界或可见性转换点时连接线链。分支点不得任选路径。
4. 优先从 HLR 边的曲线类型直接写出解析实体：直线写为 `LINE`，圆弧写为 `ARC`，满圆写为 `CIRCLE`，其余受目标 DXF 支持的曲线写为 `ELLIPSE/SPLINE`。禁止把所有边无差别执行 `discretize()` 后写成折线；只有目标版本不支持或解析恢复失败的曲线才允许离散，并记录原因、弦高误差和源边映射。
5. 合并共线同向 `LINE` 和同心同半径连续 `ARC`；闭合满圆恢复为 `CIRCLE`。折线删除重复顶点并合并连续共线段；曲线重建须记录最大偏差，保持端点、切向、闭合和孔槽拓扑。闭合链不得直接使用破坏首尾拓扑的开放折线降点算法。
6. 合并后在原分组再次去重。禁止跨视图去重，禁止跨可见/隐藏区间连接，也禁止用固定最短长度规则删除真实小孔、窄槽、倒角端点或可见性分界。
7. 只有二维图形完全相同且不存在局部遮挡差异时，重复压铆件才可用 `BLOCK/INSERT` 复用。

## 4. 输出证据和结构门禁

1. 保存 HLR 原始、优化后和最终待导出的实体/顶点数、解析实体类型、短段、重复段、文件预估及各视图/源对象贡献；记录几何容差、简化前后差值以及全部 HLR 分组的取舍。任何未说明的非空分组被丢弃均判失败。
2. 图层、线宽、线型定义和比例按 [DXF 图线基准](dxf-delivery.md#21-图线基准)输出。保存实际使用的线宽、线型图案、`$LTSCALE`、纸空间/模型空间设置和实体线型比例；回读替换线型、改变比例或丢失线宽即失败。
3. 属于同一物理边的连续线链应合并为一个解析实体或连续链，避免每个微小分段重新开始虚线相位；可见实线不得因离散、重合清理或线型继承而出现间断。禁止以缩短虚线图案掩盖碎片问题。
4. 项目给出的实体数、顶点数、文件大小和回读时间上限均为硬限制。无明确上限时不臆造数值，但仍须消除无理由的短段爆炸和单个滚花/螺纹对象异常占用。
5. 使用 `scripts/dxf_performance_audit.py <最终DXF>` 保存结构报告；私有 `ezdxf` 用 `--vendor-path`，项目上限用 `--max-entities`、`--max-polyline-vertices`、`--max-file-size-mb`、`--max-read-seconds` 传入。状态 `structural_pass_target_reader_pending` 只表示结构预检通过。
6. 从源 STEP 到优化结果逐视图复核外轮廓、功能孔槽闭环、压铆孔/中心/控制轮廓、尺寸落点、可见性转换和至少三个不共线特征。任何孔闭合、轮廓断裂、特征误连、隐藏线变实线、尺寸落点丢失或镜像变化均须回退。
7. `dxf_performance_audit.py` 必须直接从最终 DXF 检查 `visible_hidden_exact_overlap=0`、`VISIBLE=CONTINUOUS`、`HIDDEN` 使用已定义的非连续线型且全局线型比例为正；生成器不得把这些结果硬编码为 `pass`。
8. 最终 DXF 回读预览必须同时做整体和局部检查：可见轮廓连续清晰；隐藏线具有稳定虚线节奏；内部功能轮廓齐全；线端接合无肉眼可见缺口；同一边不因碎实体出现点状、双线或相位乱跳。截图或人工观察不满足任一项即返工生成源。`readback_line_review` 只能在检查最终预览后填写，未检查时必须为 `pending/false`，禁止在生成 DXF 时预置零缺陷。

工程图检查记录必须包含 `projection_validation`，供 `project_acceptance.py` 执行 A05/A10/A11，不得只写一个总 `pass`：

- 顶层：`interface`、`freecad_version`、`group_names`、`visible_group_indices`、`hidden_group_indices`、`per_view` 和 `pass`。FreeCAD 1.1 的 `group_names` 固定记录为 `V,V1,VN,VO,VI,H,H1,HN,HO,HI`。
- `per_view`：六个视图各自保存 `group_counts`、覆盖全部分组的 `accounted_group_indices`、`missing_functional_features` 和 `pass`。
- `geometry_export`：至少保存 `indiscriminate_discretization=false`、`unqualified_discretized_edges=0`、`broken_closed_loops=0` 和 `pass`。
- `linetype_validation`：至少保存 `explicit_global_scale=true`、`explicit_entity_scales=true` 和 `pass`，并附实际线型图案和比例值。
- `readback_line_review`：最终 DXF 高分辨率预览生成后，使用 `scripts/record_projection_review.py` 保存预览 SHA-256、检查人、`visible_contour_breaks`、`missing_internal_features`、`hidden_pattern_issues` 和 `pass`；人工 M02 仍须独立复核，生成器自报不能替代人工审图。

**通过条件：** 制造相关几何和可见性保持不变；重复及可安全合并的碎片已消除；原始/优化统计、主要碎片来源和源特征映射可追溯。目标 CAD 是否可交互仍须按 DXF 交付与项目验收流程验证。
